Overview

This SOP covers the end-to-end workflow for creating an ad creative brief, getting it into the Creative Tracker, and finalizing the brief with auto-generated creative names. It involves two roles: the copywriter (or anyone authoring a brief) and the project manager (PM).

1 Copywriter generates the brief

Copywriter

  1. Open Briefgen.
  2. Pick the Client in the top-right header.
  3. Pick the brief type tab: Static, Video, or Body Copy.
  4. (Optional) Pick a saved Preset to pre-fill the overview fields. To save a new preset, fill the overview fields you want to reuse, then click + Save preset and name it.
  5. Fill the Overview section. Idea Name and File Name are not required — those usually come later from the tracker.
  6. Add 1–5 creatives. Each creative is one row in the brief.
  7. Click Generate Brief. The .docx downloads to your Downloads folder. File name pattern: {Client}_{BriefType}_{Idea Name}_{YYYY-MM-DD}.docx
Auto-saves to your browser. If you close the tab, your in-progress brief is restored on reload.

2 Create ClickUp task + Google Doc

Copywriter

  1. In ClickUp, create a new task in the appropriate creative request list for this client.
  2. The task automatically generates a Google Doc link (BAD Marketing's ClickUp setup). This Doc is the canonical Request Doc that goes into the tracker.
  3. Open the Google Doc.

3 Replace the Doc placeholder with your .docx

Copywriter

  1. In the open Google Doc, click File → Open.
  2. In the Upload tab, drag the .docx that Briefgen downloaded.
  3. Google Docs imports the .docx contents, replacing the empty placeholder with your filled brief (overview + creative tables).
  4. Verify the headings, dropdowns, and creative tables look right.

4 Hand off to PM

Copywriter

  1. In the ClickUp task, mark the brief as ready for review (or however the team flags handoff — Slack ping, status change, assignee swap, etc.).
  2. The PM picks it up from here.

5 PM enters into Creative Tracker

Project Manager

  1. Open the brief Google Doc the copywriter handed off.
  2. Press Cmd+A then Cmd+C to copy the entire doc contents.
  3. Open PM Tools → the Brief → Tracker tab is selected by default.
  4. Paste into the textarea. The brief type auto-detects.
  5. Paste the Google Doc URL into the Request Doc URL field.
  6. Click Generate Tracker Rows.
  7. The result panel shows two preview tables — Block 1 (left columns) and Block 2 (right columns) — and a banner with Open {Client} Tracker ↗ if the client is recognized.
  8. Click the tracker link → opens the Creative Tracker in a new tab.
  9. In the tracker, go to the correct tab (Static / Video / Copy Tracker), click the next empty row in column A.
  10. Switch back to PM Tools → click 📋 Copy on Block 1 → switch to the tracker → paste.
  11. Click the cell at the column shown in Block 2's subtitle (usually W for Static / Copy, U for Video).
  12. Switch back to PM Tools → click 📋 Copy on Block 2 → switch to the tracker → paste.
  13. Read the Notes panel at the bottom — it explains every column we leave blank or default (e.g. Status, Platform=Meta, Copy Name auto-formula).

6 PM copies names back into the brief

Project Manager

  1. In the tracker, the formula now auto-fills the Creative Name column (Static Creative Name, Video Creative Name, or Copy Name) for the rows you just added.
  2. Select that column for those rows → Cmd+C.
  3. In PM Tools, switch to the Tracker → Brief tab.
  4. Paste into the textarea. Each line becomes a numbered item with its own 📋 Copy button.
  5. Open the brief Google Doc.
  6. For each creative row in the doc:
    • Click 📋 Copy next to the corresponding name in PM Tools (it auto-checks "filled" so you can track progress).
    • Switch to the Google Doc → click in the File Name (or Name) cell of that creative table → paste.
  7. When all rows are checked, the brief is complete.

7 Move Google Doc to client folder

Project Manager

  1. In the brief Google Doc, click the folder icon next to the title (or File → Move).
  2. Move it to the client's profile folder in Drive (Clients → {Client Name} → Briefs or wherever your team's convention is).
  3. Update the ClickUp task to reflect the brief is now in the canonical location.

Tips & gotchas

  • Adding a new client: In Briefgen, click + Add client in the top-right. You'll be prompted for a client name and (optionally) the Creative Tracker URL. The new client persists in your browser only — to share with teammates, edit clients.json in the repo and push.
  • Setting a tracker URL on an existing client: Pick the client in Briefgen → click + Tracker URL (or Tracker URL ✓ to edit) → paste the Google Sheets URL. PM Tools will pick this up automatically next time you open it.
  • Status, Platform, Copy Name, CPID, Variation Name (body copy) are always left blank in tracker output. The tracker has formulas / dropdowns that handle these. Don't fill them manually unless you know the convention for your client.
  • The "Lead" → "Hook" remap applies to Static and Video Variation Type only. Body Copy variation types (Lead, Body, CTA, Full) match the tracker dropdown 1:1.
  • "Lead Type" normalization: Brief values like "Story Lead 3" are normalized to just "Story" for the tracker. Strip variation numbers, strip trailing " Lead", case-correct.
  • Multi-line text in cells: Newlines inside a brief cell (like a multi-paragraph Body Copy) are converted to spaces in tracker TSV output, since Google Sheets interprets newlines as new rows on paste.
  • Hard-refresh after a deploy: If you don't see a new feature, press Cmd+Shift+R — GitHub Pages caches HTML aggressively.
